> 全部命令可直接复制粘贴。

## 二、环境要求

| 软件 | 版本 | 检查命令 |
|---|---|---|
| JDK | **17 或以上** | `java -version` |
| Maven | 3.6+ | `mvn -v` |
| MySQL | **8.0+** | `mysql --version` |

| npm | 9+ | `npm -v` |

## 四、建库（关键一步）

### 4.1 创建数据库并导入表结构

**方式 A：命令行（推荐）**

```bash
mysql -uroot -p < magic-club/db/init.sql
```

**方式 B：用 Navicat / DBeaver**

新建连接 → 打开 `magic-club/db/init.sql` → 全选执行。

### 4.2 这一步做了什么

`db/init.sql` 会：

1. 建库 `magic_club`（字符集 `utf8mb4`）
2. 建 12 张表：`mc_user`、`mc_post`、`mc_post_reply`、`mc_resource`、`mc_notification`、`mc_operation_log`、`mc_memorial`、`mc_invite_code`、`mc_user_token`、`mc_system_config`、`mc_config`、`mc_developer`
3. 插入初始数据：
   - **管理员账号**：用户名 `admin`，密码 `Admin123456`
   - 部门 / 帖子分类 / 资源分类等字典

> ⚠️ `init.sql` 里有 `DROP TABLE IF EXISTS`，**只在空库执行**。已有数据的库不要跑，改用 `db/migration_*.sql`。

### 4.3 验证建库成功

```bash
mysql -uroot -p -e "use magic_club; show tables;"
```

应该看到 12 张表。

## 五、启动后端

### 5.1 改数据库配置

打开 `magic-club/src/main/resources/application.yml`，改这两行：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/magic_club?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: 你的数据库密码        # ← 改成你自己的
```

### 5.2 启动

```bash
cd magic-club

# 方式一：直接跑
mvn spring-boot:run

# 方式二：先打包再跑
mvn clean package -DskipTests
java -jar target/magic-club-1.0.0.jar
```

**看到这行就是成功了：**

```
Started MagicClubApplication in 5.xxx seconds
Tomcat started on port(s): 8080 (http)
```

### 5.3 验证后端

浏览器打开或用 curl：

```bash
curl "http://localhost:8080/api/forum/posts?pageNum=1&pageSize=1"
```

返回 `{"code":"200",...}` 即正常。

> 注意：后端有统一前缀 `/api`（`context-path`），所以所有接口都是 `http://localhost:8080/api/xxx`。

## 六、启动前端

```bash
cd magic-club-web

# 1. 装依赖（第一次需要，约 1-3 分钟）
npm install

# 2. 启动开发服务器
npm run dev
```

**看到这行就是成功了：**

```
  VITE v5.x  ready in xxx ms
  ➜  Local:   http://localhost:3000/
```

### 6.1 前端如何连后端

开发环境下走 Vite 代理（`vite.config.ts`）：

```ts
server: {
  port: 3000,
  proxy: {
    '/api':     { target: 'http://localhost:8080', changeOrigin: true },
    '/uploads': { target: 'http://localhost:8080', changeOrigin: true }
  }
}
```

> ⚠️ **仓库里的代理地址可能指向线上服务器 IP**。如果本地跑，把它改成 `http://localhost:8080`。

### 6.2 验证前端

浏览器打开 <http://localhost:3000>，用 `admin / Admin123456` 登录。

## 七、目录与模块速览

### 后端（Spring Boot 3.2 + MyBatis-Plus）

```
src/main/java/cn/magicclub/
├─ controller/     接口层（9 个 Controller）
├─ service/        业务层
├─ mapper/         数据访问（MyBatis-Plus）
├─ entity/         实体类
├─ config/         Security / MyBatis-Plus / WebMvc 配置
├─ security/       ★ JWT 过滤器 + 权限校验（注解 + 拦截器）
└─ common/         统一返回、异常处理、权限常量
```

关键设计：

- **认证**：JWT + Token 落库，支持单设备登录与强制下线
- **授权**：`@RequirePermission("resource:audit")` 注解 + `PermissionInterceptor`，权限 = 角色默认 ∪ 用户自定义增量

### 前端（Vue 3 + TS + Vite）

```
src/
├─ api/            接口封装
├─ stores/         Pinia（user store 管登录态与权限）
├─ router/         路由 + 权限守卫
├─ layouts/        主框架
├─ views/          页面
├─ composables/    usePermission 等
└─ styles/         theme.css（CSS 变量双主题）
```

## 八、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `Unsupported class file major version` | JDK 版本太低 | 换 JDK 17+ |
| `Access denied for user 'root'` | 数据库密码没改 | 改 `application.yml` |
| `Unknown database 'magic_club'` | 没导 `init.sql` | 回第四步 |
| 启动报 `Port 8080 was already in use` | 端口被占 | `--server.port=8081` 或杀掉占用进程 |
| 前端页面能开但接口全 404 | 代理没配好 | 检查 `vite.config.ts` 的 target |
| 登录提示用户名或密码错误 | 账号不是 `admin`，或库是老版本 | 用 `admin / Admin123456`；老库需执行 `db/migration_*.sql` |
| `npm install` 很慢 | 网络 | `npm config set registry https://registry.npmmirror.com` |
| 中文乱码 | 库字符集不是 utf8mb4 | 重建库，确保 `init.sql` 里的建库语句生效 |

## 九、生产部署

生产环境不要用 `mvn spring-boot:run` / `npm run dev`，标准做法：

```bash
# 后端打包
mvn clean package -DskipTests
java -jar target/magic-club-1.0.0.jar

# 前端构建
npm run build          # 产物在 dist/，交给 Nginx 托管
```

Nginx 需要把 `/api` 反代到 `127.0.0.1:8080/api`，`/` 指向前端 `dist` 目录。
